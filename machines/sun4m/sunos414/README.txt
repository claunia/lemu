SunOS 4.1.4 on QEMU's SPARCstation 5 (microSPARC II, 256 MB, cg3 graphics, SCSI disk, Lance network)

Run ./run.sh (macOS 26+ arm64, Linux x86_64/aarch64 with glibc 2.34+ and X11/XWayland) or run.cmd (Windows 10+ x64).
Log in as root, no password, at the console in the QEMU window (about 30 s after the start), telnet localhost 41423 or rsh localhost port 41414. Telnet and rsh let root in without a password. Both ports listen on this computer only.
Type /usr/openwin/bin/openwin for OpenWindows 3, or sunview for SunView. The screen is 1280x1024. RES=1152x900 ./run.sh gives another size, from 640x480 to 3200x1800 with a width that 8 divides (Windows: set RES=1152x900, then run.cmd). The text console uses the top part of a big screen.
Installed: Sun C (cc); gcc 3.0.4, GNU make 3.82, bash 3.2, gawk 3.1.6, GNU tar, gzip and binutils 2.14 in /usr/local/bin; Lotus 1-2-3 1.2; Netscape 1.0 and Navigator 4.61; NCSA Mosaic 2.7b4; the SunView games 2048, bubble, flap, mines, snake, sokoban and tetris in /usr/local/bin, with their sources in /home/games; Micropolis for SunView in /usr/simcity-sunview; Altsys Virtuoso 1.0, a NeWS drawing program from 1993, in /usr/virtuoso; Mathematica 2.2.3 in /usr/local/mathematica; Island Productivity Series 3.0 (IslandWrite, IslandDraw, IslandPaint, 1992) in /usr/local/island; Lucid Energize 2.5 (Lucid C/C++ 3.1 and Lucid Emacs 19.7) in /usr/energize; FrameMaker 2.1.1 in /home/framemaker; SimCity for HyperLook (DUX Software, 1992) in /usr/simcity-hyperlook; Interleaf TPS 4.0 in /usr/local/interleaf; MathCAD 2.53 in /usr/local/mathcad; WordPerfect 6.0 and the text version WordPerfect 5.2+ in /home/wp60; SoftWindows 2.0 (MS-DOS 6.22 and Windows 3.11) in /home/SoftWindows2; the CorelDRAW 3.0 demo (also CorelCHART, CorelMOSAIC, CorelPAINT, CorelSHOW and CorelTRACE) in /home/corel.
Apps: start them in a cmdtool under OpenWindows (root's shell is csh). 1-2-3: setenv WINDOW_MGR olwm; set path=(/usr/lotus/123.v12/sun4sol1/bin $path); 123. Navigator 4.61: setenv XNLSPATH /usr/netscape/nls; /usr/netscape/netscape. Netscape 1.0: /usr/netscape1/netscape. Mosaic: /usr/mosaic/Mosaic-sun-2.7b4. Virtuoso: virtuoso. To open a sample drawing, click Open..., type /usr/virtuoso/SampleArt/Earth.vrt in the File field and press Return (more drawings are in that folder). SunOS has no name server set up, so the browsers need addresses on 192.168.1.x.
NeWS PostScript: psh /home/NeWS/hello.ps in a cmdtool opens a Hello World window, with comments in the file. Click the window to close it.
Games: they are SunView programs. Type sunview at the console, then 2048, tetris and so on in its shelltool. Under OpenWindows they start too, with wrong colours.
Micropolis, the city game, is a SunView program too: type micropolis in the shelltool. micropolis -mono plays in black and white. Source: https://github.com/tenox7/micropolis-sunview.
Mathematica 2.2.3: in SunView, type math in the shelltool. Plots such as Plot[Sin[x], {x, 0, 2 Pi}] open in a window of their own. Quit[] ends math. Under OpenWindows, mathematica & in a cmdtool opens the notebook: type a formula, then press Shift-Return. The password in /usr/local/mathematica/Install/mathpass is for the network card address that QEMU uses by default, 52:54:00:12:34:56: with another mac=, Mathematica needs a new password.
Island Productivity Series 3.0: type IslandWrite &, IslandDraw & or IslandPaint & in a cmdtool under OpenWindows. A file name after the command opens it, e.g. IslandDraw /usr/local/island/ioffice_3.0/demo/Draw/golden_gate.vec &. More samples are in the demo and more_demo folders there. The licence server starts at boot. Its licence is for the network card address that QEMU uses by default, 52:54:00:12:34:56: with another mac=, the apps need a new licence.
Energize 2.5: in a cmdtool under OpenWindows, type set path=(/usr/energize/bin $path), then /usr/energize/ostore/etc/start_servers (its ObjectStore database servers), then start_energize.
FrameMaker 2.1.1: /home/framemaker/bin/maker in a cmdtool under OpenWindows (imaker starts International FrameMaker, viewer starts FrameViewer). For a sample, click Open..., type /home/framemaker/docs/Demo.doc and press Return. The passwords in /home/framemaker/.fminit2.0/framepasswd are for the network card address that QEMU uses by default, 52:54:00:12:34:56: with another mac=, FrameMaker needs new ones.
SimCity for HyperLook: /usr/simcity-hyperlook/SimCity in a cmdtool under OpenWindows. It has sound.
Interleaf TPS 4.0 and MathCAD 2.53 are SunView programs. Type sunview at the console, then /interleaf/tps4.0/user/tps & or mathcad & in the shelltool. Interleaf asks about its demo and tutorial at each start, then shows its desktop. To stop the questions, select the demo_menus_enable icon there and choose Cut from the right-button menu. Its tour is the Interleaf Demo document in the System cabinet: select it, then choose Open from the right-button menu. mathcad /usr/local/mathcad/MathCAD_Examples/surface.mcd & opens an example; more are in that folder. Their passwords (in /usr/local/interleaf/data/host and /usr/local/mathcad/mcaddir/mcad.pw) are for the network card address that QEMU uses by default, 52:54:00:12:34:56: with another mac=, they need new ones.
WordPerfect 6.0: xwp in a cmdtool under OpenWindows. xwp /home/wp60/samples/newsletter opens a sample; more are in that folder. The text version, WordPerfect 5.2+, runs in a window of its own: env WPTERM52=xcolor /home/wp60/shbin10/wpxtool -e wp & (F7 exits). The licence server starts at boot and needs the host name solqemux.
SoftWindows 2.0: softwindows in a cmdtool under OpenWindows. Click Exit to SoftWindows on its registration page, then type win at the C:\> prompt for Windows 3.11.
CorelDRAW 3.0 demo: coreldraw in a cmdtool under OpenWindows (also corelchart, corelmosaic, corelpaint, corelshow and coreltrace). Answer Yes when it asks for the demonstration version. coreldraw /home/corel/corel_sun/draw/samples/jukebox.cdr opens a sample; more are in that folder.
Sound: SunOS plays its sound (/dev/audio) on this computer's sound output. Try /usr/demo/SOUND/play -v 100 /usr/demo/SOUND/sounds/spacemusic.au: SunOS starts with a low volume, and -v 100 is full.
battalion (/usr/battalion) is a Solaris 2 program: it does not run on SunOS 4.
Click in the QEMU window to grab the mouse; Ctrl-Alt-G (Ctrl-Option-G on a Mac) lets it go. Right after OpenWindows or SunView starts, the pointer stands still for the first moment of mouse movement: SunOS is checking the mouse's line speed.
CD-ROM: CD=/full/path/file.iso ./run.sh puts a CD in a drive at SCSI target 6. In SunOS: mount -rt hsfs /dev/sr0 /cdrom.
Extra QEMU options are passed through, e.g. ./run.sh -display vnc=127.0.0.1:1.
The terminal holds the QEMU monitor. quit there stops QEMU at once.
Network is QEMU user mode NAT on 192.168.1.0/24: SunOS is 192.168.1.123 (hostname solqemux), the host side is 192.168.1.10. SunOS has no default route, so it reaches only 192.168.1.x.
An idle SunOS uses a few percent of one host core: QEMU halts the CPU in SunOS's idle loop (-M SS-5,sunos-idle=off turns that off).
Run shutdown -h now as root. QEMU exits when SunOS has halted.
macOS: if the binary is blocked, run xattr -cr . in this folder.

AI agents (macOS, Linux): in this folder, claude mcp add lemu -s user -- "$PWD/bin/macos-arm64/qemu-system-sparc" -mcp-bridge (on Linux bin/linux-x86_64 or bin/linux-aarch64) lets an agent such as Claude Code see the screen and use the keyboard, mouse and serial ports of the running VM. See MCP.md in the QEMU source.
QEMU source: https://github.com/tenox7/lemu branch master (GPLv2, see bin/COPYING). qemu-system-sparc --version names the commit.
